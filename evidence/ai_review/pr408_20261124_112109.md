```python

    w, c, _cl, _dg = run_seq(lc.word, lc.cell, 1, arm_at=30, no_rearm=True)

    r3 += int((w, c) != (truth_trace[t][2], truth_trace[t][3]))
```

`run_seq(..., ticks=1, arm_at=30, ...)` loops only `t in range(1, 2)`, so `arm_at=30` is never reached. The `no_rearm=True` branch is therefore dead. The rival labelled “a re-arm only initialises an unarmed cell” is actually “no arm at tick 30 at all”. It still differs from the truth, so G6 stays green, but the printed rival is not the rival being claimed. This matters because G6’s VERIFIED row says the six rivals fail on the printed numbers; one of those failures is produced by a logic bug, not by the competing rule. A mutant that repairs the rival loop could change the score without exposing the defect.
