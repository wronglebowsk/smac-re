6. **P2 — `scripts/m334_powershort_census.py:181-189`: `reads_of()` only detects absolute `0x94d650` text, so “0 reads of block+0x220” is not a complete read census.**  
   The instrument has a separate `folded_stores_to()` scan for writes through a folded block pointer, but `e_reads` is purely operand-text based. A read like `mov eax,DWORD PTR [edi+0x220]` after `lea edi,[...+0x94d430]` would not name `0x94d650` and would be missed. The VERIFIED “0 reads” claim is therefore source-only/absolute-only, not a whole-path read proof.

7. **P2 — `scripts/m334_powershort_census.py:404-417`: `G2` does not prove the clamp stores actually store zero.**
