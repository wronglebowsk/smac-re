The instrument only measures literal `mov` writes and then declares those laws. That is a real defect in the instrument’s argument decoding: the “sole def / last-overwrite” claim is not fully read from bytes.

Why it matters: these slot-liveness claims are load-bearing for classifying non-field `+2fc`/`+308` reads as block accesses. A hidden non-`mov` stack-slot write invalidates the argument, yet the gate remains green.

